Několik komentářů:

1) zápis do souboru by mohl mít trochu víc hlavu a patu:

	File.open("./outputs/skript.txt", "w") do |line|
		line.puts s
	end
  
-- proč se proměnná s řídícím objektem souboru jmenuje "line"? To nemá žádný smysl, přece to není žádná řádka ničeho. Běžně a rozumně zde můžete třeba užít "f" jako file.

Ale hlavně, pokud chci zapsat jeden řetězec:

File.write("./outputs/skript.txt", s)

2) získat všechny klíče nebo hodnoty hashe lze snadno bez iterátorů:

	a = [] #připravím si pořadí názvů pro výstup v podobě pole
	sorted_hash.each do |key, val|
		a << key.to_s
	end

nahradíte 

a = sorted_hash.keys

3) u funkce use se mi moc nelíbí ta logika na konci -- sestavujete nějaké pole a podmínku máte až u případného return. Lépe by bylo něco jako

if mode == "numbers"
	s = [] #připravím si pořadí čísel pro výstup v podobě pole 
	sorted_hash.each do |key, val|
		s << val.to_s 
	end
	return s 
else	
	a = [] #připravím si pořadí názvů pro výstup v podobě pole
	sorted_hash.each do |key, val|
		a << key.to_s
	end
	return a
end

4)

namísto

FileUtils.mkdir "./outputs" if !File.exist?("outputs")

bych užil

FileUtils.mkdir "./outputs" unless File.exist?("outputs")

ale hlavně

FileUtils.mkdir_p("./outputs")
